# Hosted-platform variable table

> Principle: **exactly one required field** (`LLM_API_KEY`); everything else is either a hidden
> preset, generated by template variable functions, or has a default.
> Platform best practice: give every variable a description, and never hard-code credentials —
> generate secrets with `secret()`. Secrets are handled on the model side only:
> one required key, endpoint from `LLM_PROVIDER` (or `LLM_BASE_URL`), model list discovered at start.

## 1. Visible variables (shown in the deploy form)

| Variable | Visibility | Value | Description (paste into the Description field) |
|---|---|---|---|
| `LLM_API_KEY` | **required** | empty, deployer fills | Model API key for an OpenAI-compatible endpoint. Optional — without it you can still deploy and sign in, but agent tasks cannot run |
| `JWT_SECRET` | visible | `${{secret(64)}}` | Session signing secret, generated automatically. **Do not change** — existing sessions become invalid |
| `GRAPE_ADMIN_PASSWORD` | visible | `${{secret(24)}}` | Password for the `/admin` console; visible in the Variables tab. Change it after deployment |
| `LLM_PROVIDER` | optional | empty | Provider preset: `openai` / `deepseek` / `openrouter` / `opengw`. Set it and you can leave `LLM_BASE_URL` empty |
| `LLM_BASE_URL` | optional | empty | OpenAI-compatible endpoint, e.g. `https://<your-gateway>/v1`. Leave empty when a `LLM_PROVIDER` preset is set |
| `LLM_MODEL` | optional | empty | Default model id; `<model-id>` or `custom/<model-id>` both work. **Recommended empty**: every model returned by the endpoint's `/v1/models` is registered at startup and can be switched in Agent Settings |
| `LLM_PROVIDER_ID` | optional (advanced) | `custom` | Provider identifier used inside the engine config; change it only if you want a custom name |

## 1.1 Model endpoint: pick one of three

| Case | Variables to set | Notes |
|---|---|---|
| OpenAI API key | `LLM_API_KEY` + `LLM_PROVIDER=openai` | endpoint defaults to `https://api.openai.com/v1` |
| DeepSeek / OpenRouter | `LLM_API_KEY` + `LLM_PROVIDER=deepseek` (or `openrouter`) | endpoint defaults accordingly |
| Own / corporate gateway | `LLM_API_KEY` + `LLM_BASE_URL=https://<your-gateway>/v1` | leave `LLM_PROVIDER` empty |

- To pin a default model, also set `LLM_MODEL=<model-id>` (`custom/<model-id>` works too).
- **Leaving `LLM_MODEL` empty is recommended** — the container registers every model the endpoint
  returns, so deployers can switch models later.
- The result is written to `$HOME/.config/opencode/opencode.json`; the log prints
  `[entrypoint] engine config -> … (provider=… default=… models=N baseURL=…)`.
  A missing line or `models=0` means the model side is not configured.

## 2. Hidden variables (presets, not exposed in the form)

| Variable | Value | Why |
|---|---|---|
| `COOKIE_SECURE` | `true` | The platform serves HTTPS only; production checks enforce it |
| `GRAPE_PORT` | `3000` | Must match the container port and the template's public port |
| `DEVOPS_DB_BACKEND` | `sqlite` | Default SQLite; data lives on the `/app/data` volume |
| `GRAPE_HOSTED_BOOTSTRAP` | unset (auto) | Hosted bootstrap switch: `1` always, `0` never, unset = auto-detect (on these platforms it always runs). The bootstrap fills in the JWT secret, the public base URL and the engine model config |

## 3. Injected by the platform — do **not** set by hand

| Variable | Source | Used by Grape |
|---|---|---|
| `RAILWAY_PUBLIC_DOMAIN` | injected once a domain exists | `entrypoint.sh` derives `server_base_url` and `TRUSTED_HOSTS` from it |
| `PUBLIC_DOMAIN` | optional generic alias for any platform | same purpose, checked before the platform-specific one |
| `RAILWAY_PRIVATE_DOMAIN` and other `RAILWAY_*` | injected | not used |

## 4. Optional escape hatches (troubleshooting only)

| Variable | When to use |
|---|---|
| `SERVER_BASE_URL` | When the platform injects no domain (e.g. the domain is created after the container starts), set `https://<your-domain>`. **Takes priority** over every platform variable. Keep it empty otherwise — never hard-code a domain |
| `TRUSTED_HOSTS` | Derived from the base URL by default; set it explicitly if a proxy chain breaks host detection |

## 5. Template layout the platform must be configured with

| Item | Value |
|---|---|
| Service source | `https://github.com/<your-org>/grape` (default branch `main`) |
| Public networking | **Enable**, HTTP, port `3000` (preset it so the domain exists before first boot) |
| Volume | Attach, mount path **`/app/data`** |
| Region | **Not pinned** — deployers use their own default region |
| Health check | `/api/health` (declared in `railway.json`, 300 s timeout) |

## 6. Template variable functions

| Function | Behaviour | Example |
|---|---|---|
| `secret(length?, alphabet?)` | random secret, 32 chars by default | `${{secret(64)}}`, `${{secret(64, "abcdef0123456789")}}` |
| `randomInt(min?, max?)` | random integer in range, 0–100 by default | `${{randomInt(1, 65535)}}` |
